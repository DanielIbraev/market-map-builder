## `demo.gif` (to record)

The main README references `docs/demo.gif`. Record a short (~15–30s) screen
capture and save it here as `demo.gif`:

1. A terminal running, e.g.:
   ```bash
   python -m src.main map "AI coding assistants" --mock
   ```
   (or a live run with a real key)
2. Then opening the resulting `vault/ai-coding-assistants/` folder in Obsidian
   and showing the **graph view** with the interlinked company notes.

Suggested tools: macOS screen recording + [Gifski](https://gif.ski/), or
[`ttygif`](https://github.com/icholy/ttygif) / [`asciinema`](https://asciinema.org/)
for the terminal portion. Keep it under ~5 MB so it renders inline on GitHub.
