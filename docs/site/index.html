How this works

Research runs locally
The Market Map Builder CLI researches a sector with AI + web search on your machine. API keys never leave your laptop and never touch this site.
The site is pure static files
No backend, no database, no runtime API calls — there is nothing to hack and no credentials to steal. Locked-down CSP; zero third-party requests.
Every fact is cited & dated
Company profiles carry per-fact source links and a last-verified date. Unverifiable figures stay “unknown” — never invented.
